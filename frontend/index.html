À propos de SIMONE

🎯 Objectif

SIMONE est une application de traduction vocale en temps réel développée dans un cadre académique et professionnel. Elle utilise des modèles d'IA avancés pour offrir une transcription et une traduction de haute qualité.

🛠️ Technologies

  • Whisper (OpenAI) - Transcription audio de pointe
  • Marian NMT (Helsinki-NLP) - Traduction neuronale
  • FastAPI - Backend performant avec WebSocket
  • Web Audio API - Capture audio dans le navigateur

📊 Fonctionnalités

  • Traduction vocale en temps réel
  • Support multilingue (FR, EN, ES, DE, IT, PT)
  • Synthèse vocale de la traduction
  • Historique des traductions
  • Export PDF/DOCX
